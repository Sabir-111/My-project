# 📌 About The Project

**Elan.az** is a modern classifieds and marketplace platform designed for
users in Azerbaijan.

The platform allows users to discover, search, publish and manage listings
through a clean and responsive interface.

The project also includes a dedicated **administration dashboard** with
user management, listing management, reports, payments, analytics,
audit logs, support tools and administrative controls.

The architecture is designed to support intelligent marketplace features
and future AI-powered functionality.

```bash
cd My-project
```

---

## 3️⃣ Install dependencies

```bash
npm install
```

---

## 4️⃣ Configure Supabase

Create a `.env` file based on `.env.example`.

Example:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Replace the placeholder values with your own Supabase project credentials.

---

## 5️⃣ Start the development server

```bash
npm run dev
```

The terminal will display the local development URL.

# 🔐 Security

Security is an important part of a marketplace application.

Never commit sensitive credentials to GitHub.

### Never expose:

```text
SUPABASE_SERVICE_ROLE_KEY
DATABASE_PASSWORD
JWT_SECRET
PAYMENT_SECRET
PRIVATE_API_KEYS
SMTP_PASSWORD
```

Only use environment variables that are safe for the browser with the
appropriate `VITE_` prefix.

### Example:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> Never place a Supabase `service_role` key in frontend code or in a
> public GitHub repository.

---

# 🛡️ Production Security Checklist

Before launching the platform publicly, verify:

- [ ] Authentication is configured
- [ ] Supabase Row Level Security is enabled where required
- [ ] Database policies are reviewed
- [ ] Storage policies are reviewed
- [ ] Admin permissions are restricted
- [ ] Sensitive environment variables are protected
- [ ] User input is validated
- [ ] File uploads are restricted
- [ ] Rate limiting is considered
- [ ] Payment secrets are protected
- [ ] Production database access is reviewed
- [ ] Error messages do not expose sensitive information
